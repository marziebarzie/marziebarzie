# hi, I'm marzie ✨

I build where craft meets systems: cozy browser games, AI agents that do real work, and creative tools.

My background spans AAA art direction, fractional CTO work, games taken from first build to ship, an early start with generative image tools, and a cybersecurity habit I never put down.

## What I'm building

- **Kitty Clicks**: a cozy incremental browser game with cloud saves and a live leaderboard, running on Cloudflare Pages, Workers, and KV.
- **Reseller agent**: a scheduled pipeline that turns product photos into marketplace-ready listing drafts, sends them for human review, and costs well under a cent per item to run.
- **Site analytics dashboard**: a configurable multi-site analytics view for developers who manage client sites. *(in progress)*
- **STARLITE**: dark-sky field intelligence, built for the Build with Gemini program. ([repo](https://github.com/marziebarzie/buildwithgemini-starlite))
